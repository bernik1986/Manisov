# CrewDeck CRM — полный каталог пользовательских сценариев

Документ фиксирует максимально полный перечень пользовательских сценариев в текущей версии системы.

---

## 1. Вход, сессия, выход

1. Успешный вход с валидным логином/паролем.
2. Ошибка входа с невалидными данными.
3. Повторный вход после выхода.
4. Выход через кнопку `Выйти`.
5. Авто-редирект на `/login` при невалидной/истекшей сессии.
6. Доступ к приватным маршрутам без сессии → редирект на `/login`.

## 18. Ролевые ограничения и доступ

1. Viewer не видит Users/Logs в меню.
2. Viewer при прямом переходе на `/users` → редирект в `/menu`.
3. Viewer при прямом переходе на `/logs` → редирект в `/menu`.
4. Admin видит и открывает все приватные разделы.

---

## 19. Сценарии ошибок и устойчивости

1. Ошибки API показываются пользователю текстом.
2. Отсутствие данных не приводит к падению интерфейса.
3. Повторные действия после ошибки работают (retry-сценарии).
4. Навигация назад/вперёд браузера не ломает состояние страницы.

---

## 20. Полный регрессионный прогон перед релизом

1. Перезапуск окружения: `docker compose down` + `docker compose up -d --build`.
2. Backend автотесты: `python -m pytest -v --tb=short`.
3. E2E автотесты: `npm run test:e2e -- --reporter=list`.
4. Проверка отсутствия fail в обязательных критических сценариях.
