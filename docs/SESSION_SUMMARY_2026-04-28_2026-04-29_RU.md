# Отчёт по работам: 28–29 апреля 2026

Сводка по изменениям в проекте **Parcer** (CV for seafarers) за **вчера** и **сегодня**.

---

## 28 апреля 2026 (вчера)

### Шаблоны и генерация документов
- Проверка и доработка анкет: **CHANDRIS_APPLICATION**, **OVERSEAS_APPLICATION**, **CENTURY_APPLICATION**, **JHI_BULK_APPLICATION**, **JHI_TANKERS_APPLICATION** и набор шаблонов **COE** (папка CENTURY COE / DONA BIBI и др.) — синтаксис Jinja/XML в DOCX, при необходимости циклы для **сертификатов** и **sea service / опыта**, исправление кривых плейсхолдеров (в т.ч. отдельная правка **MARIJEANNIE … 3O COE** — фигурные скобки `{{ }}`).
- Согласование контекста с полями кандидата; при отсутствии данных поля по возможности оставляются пустыми — без «левых» подстановок.

### Карточка кандидата (CRM)
- **K. Flag Documents** и **Family Contacts**: восстановление **полной очистки** опциональных полей — для PUT формируется payload со **явным `null`**, где пользователь очистил поле (устранено молчание при `exclude_unset` на бэкенде после обрезки пустых строк на фронте).

### Загрузка и скачивание файлов
- **Скачивание шаблонов из Manager Templates**: улучшен разбор заголовка **Content-Disposition** (в т.ч. `filename*=UTF-8''…`), чтобы в загрузках было **понятное имя файла** (имя шаблона до системных суффиксов), а не только «Template 1 …».
- На стороне **Manager Templates**: клиентская **валидация расширений** при загрузке (DOC/DOCX/PDF); на сервере — **лимиты размера** и **проверка расширения** для загрузки в дерево шаблонов.

### Безопасность API и логина
- Закрыты ранее незащищённые запросы: **GET `/candidates`**, скачивание вложений — с **JWT / ролями**.
- **Защита от перебора пароля**: счётчик неудачных попыток и **временная блокировка** после порога попыток.
- Заголовки для ответов с файлами: **`X-Content-Type-Options: nosniff`**, **`Content-Disposition` как вложение** где уместно.
- После проверочной отладочной записи (**agent log**) снята **диагностическая инструментализация** по флаг-документам и family contacts.

### Тестирование за 28 число (в процессе итераций)
- Расширены **pytest** (загрузка шаблонов, auth, throttle, очистка полей через `null`).
- **`conftest`**: сброс throttle логина между тестами, чтобы избежать склейки тестов.
- Прогон **Playwright E2E** при подготовке к коммиту.

Итог этой работы многократно **коммитился и пушился** по мере включения задач безопасности, CRM и правок клиента.
